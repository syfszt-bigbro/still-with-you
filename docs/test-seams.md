# 拟确认的验收缝

测试只观察用户可见或公开数据接口，不依赖私有实现细节。

1. **全新安装缝**：在空数据目录启动，完成四步设置；退出重开后人物、形象、记忆和设置仍在，示例人物不会混入。
2. **私人导入缝**：导入虚构照片与多种聊天格式后，程序显示准确数量、身份和来源；原文件及派生资料只进入指定本机数据目录。
3. **动作形象缝**：选择照片后先显示真实头像和代表动作预览；缩放与移动取景会改变预览；确认后才替换现有形象，取消或生成失败时旧动作包不变；再次进入可恢复上次取景。给定固定测试图可生成头像和完整动作包，桌面角色能加载、切换动作、拖动并响应鼠标。
4. **记忆聊天缝**：给定固定 Persona、Relationship Memory 与聊天输入，请求只包含相关证据；回复可自然提起往事，但不得把 AI 生成内容当事实。
5. **纠正与版本缝**：提交“她不会这样说”后，下一次请求包含纠正；可查看并回滚上一版本。
6. **API 与成本缝**：无 Key 时离线功能正常；Key 只进入钥匙串；测试连接和付费调用只能由用户主动触发；网络失败保留用户输入。
7. **备份恢复缝**：完整备份往返保留计划、聊天、记忆、纠正和生成后的人物形象，不包含任何 API Key 或取景工作图。
8. **公开仓库隐私缝**：扫描源码、Git 历史、发布包和日志，禁止真实姓名、聊天原文、照片、声音、邮箱、API Key、高熵凭据和开发机绝对路径。
9. **历史导入缝**：导入只新增原文，不自动创建总结；JSON 说话人字段、TXT/Markdown 的“我：/她：”格式和 WeFlow Markdown 都返回真实说话人候选并等待用户确认；JPG 能本机 OCR 并保留左右位置，扫描 PDF 能 OCR，DOCX 能提取正文和说话人；WeFlow 的会话 ID+消息序号以及文档内容哈希+片段序号防止误去重；重复导入同一文件不会增加记录；未确认记录不参与口吻学习；可撤销本次导入且不影响旧记录；总结替换或删除不改变原文。
10. **语音路由缝**：无配置时使用系统朗读；只有同时启用云语音并提供音色 ID 才走百炼；密钥或网络失败自动回退系统朗读。
11. **干净下载缝**：从公开 GitHub 新目录克隆后，只按 README 操作即可通过测试、构建并启动；不依赖任何私人原型或本机私人目录。
