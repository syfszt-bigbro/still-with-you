# 界面设计方向

## 首次设置：把痕迹变成陪伴

```text
┌──────────────────────────────────────────────────────────────┐
│ 她一直都在                                      1 / 4  本地保存 │
│                                                              │
│  ○──────●──────○──────○   ← 痕迹线                           │
│  名字   形象    记忆   连接                                   │
│                                                              │
│               [照片预览 / 透明动作预览]                        │
│                                                              │
│  把一张照片变成桌面角色                                       │
│  原图与生成结果只保存在这台 Mac。                              │
│                                                              │
│  [选择照片]                         [稍后再说]  [生成动作形象] │
└──────────────────────────────────────────────────────────────┘
```

四步只有一个主动作：

1. 名字与边界：陪伴者代号、怎么称呼用户、不可越过的现实边界。
2. 形象：照片在本机抠图，生成头像及九种动作帧；失败时保留原图并可重试。
3. 记忆：导入聊天或口述，预览识别数量、双方身份和将要提取的内容后再确认。
4. 连接：选择 DeepSeek、OpenAI 或兼容端点；密钥进钥匙串；测试会明确提示可能计费。

## 日常主界面

沿用现有计划、专注、运动、统计、记忆、设置和独立聊天窗口。桌面透明角色仍支持拖动、鼠标靠近、绕圈、快速移动、边角放置、点击聊天和右键动作。

新增两处：

- 记忆页顶部显示“人物层 / 关系记忆 / 纠正”三类资料及来源。
- 每条模拟回复可选择“她不会这样说”，填写一句纠正并立即重试；旧回复不删除，纠正形成新版本。

## 写在最后

你喜欢过的人，不论你们有没有真正走到一起，也不论那段同行持续了多久，都可能在你身上留下不可磨灭的痕迹。

这个程序不是为了把谁困在过去，也不是让一段模拟替代真实的人。它只是帮你把那些聊天、照片、习惯和片段妥善收好，让你有机会看清：那段情感给过你什么，你又因此成为了怎样的人。

我们不应把记忆变成执念。真正好的情感，即使没有结局，也应当让人更坦荡、更温柔、更有勇气向前。愿你保存那些照亮过你的部分，也把自己带往更明亮的生活。

这就是“她一直都在”的初衷：不是让她永远停在这里，而是让被她改变过的你，继续向阳而行。
